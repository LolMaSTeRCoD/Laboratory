# Перенос проекта в GitHub

Источник: локальная рабочая папка `G:\Cady`.
Назначение: приватный репозиторий `LolMaSTeRCoD/Laboratory`, ветка `main`.

В систему контроля версий входят действующий Godot-проект, игровые модели,
текстуры, музыка и SFX, редактируемые `.blend`, исходные данные MakeHuman,
референсы, тесты, сборочные скрипты, документация и сохранённые исходники ранних
версий. Бинарные ресурсы отслеживаются Git LFS.

Не загружаются воспроизводимые кэши, результаты профилирования, временные рендеры,
промежуточные сборки, `.blend1`, локальные резервные копии и установленные
дистрибутивы Blender/Godot. Они не удаляются с исходного компьютера.

Готовая Windows-сборка публикуется отдельным релизом, а не добавляется в историю
исходников. Контрольные SHA256 архива и EXE проверяются перед загрузкой.

После уточнения локальная рабочая папка перенесена в уже существующий checkout
**`E:\Laboratory`**. Его `.git` и remote `origin` сохранены. Дальнейшие изменения,
запуск и сборки на этом компьютере выполняются здесь.

`G:\Cady` оставлен владельцу для проверки и самостоятельного удаления.

## Локальный перенос

Скопированы 15 697 файлов (7 700 613 804 байта): игровые файлы, инструменты,
исходники, архивы, история локальных проверок и готовая сборка. Каждый файл
сравнен с источником по SHA256, несовпадений нет. Бинарные объекты Git LFS
скопированы отдельно и прошли `git lfs fsck`.

Сохранена существующая Git-база `E:\Laboratory`; метаданные `.git` старой папки
не заменяли её. Кэш `GodotRebuild/.godot` пересоздаётся импортом на новом месте.
Одноразовая проверочная копия `Archive/GitHubTransferCheck` не дублировалась;
исходный экземпляр по-прежнему находится в старой папке.

Исторические JSON/логи внутри `Builds` и `Archive` могут содержать старые пути.
Они сохранены как история. Старые скрипты очистки блокируют применение планов
после переноса, пока не будут подготовлены новые проверенные планы.

## Последующие изменения

```powershell
git status
git add <изменённые-файлы>
git commit -m "Описание изменения"
git push
```

Git LFS загружает бинарные объекты при обычном `git push`. Для восстановления
на другом компьютере нужны `git clone` и `git lfs pull`.

Проверки перед отправкой: отсутствие секретов в отслеживаемых файлах, корректные
Git LFS указатели, отсутствие кэшей и установочных программ в индексе, проверка
ссылок на игровые ресурсы. Аудит переноса не заменяет художественную приёмку
моделей или повторное полное прохождение игры.

## Проверка подготовленной копии

12 ноября 2026 года подготовленное Git-дерево развёрнуто в отдельную папку без
старого `.godot`. Первый headless-импорт Godot завершился с кодом 0, без ошибок
движка. В этой копии прошли `placement_combat_smoke`, `ui_economy_smoke` и
`camera_orbit_smoke`: размещение и бой, UI/экономика/ауры и камера.

Проверены синтаксис и вычисление путей сборщика в другом каталоге, включая путь
с пробелами. Проверены наличие и SHA десяти внешних репозиториев. Готовые EXE и
ZIP сверены с SHA256 ранее подготовленного релиза 0.6.0. В процессе переноса
полная регенерация моделей и повторная сборка EXE не выполнялись.

# Environment scans

The diffuse, OpenGL normal, and roughness maps in this folder are 1K CC0 1.0 assets by Poly Haven, downloaded through the public API. Full source URLs are recorded in `sources.json`.

- [Aerial Grass Rock](https://polyhaven.com/a/aerial_grass_rock)
- [Brown Mud Leaves 01](https://polyhaven.com/a/brown_mud_leaves_01)
- [Mossy Rock](https://polyhaven.com/a/mossy_rock)
- [CC0 license](https://polyhaven.com/license)

Powered by Poly Haven. These are texture maps, not background pictures; they are applied to actual terrain, cave and boulder geometry. Procedural meshes and animations are authored for this project in `scripts/world_art.gd`.
